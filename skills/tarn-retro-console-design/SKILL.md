# Tarn - Retro Console Interface Design

## Purpose
This skill focuses on creating intuitive, aesthetic, and functional text-based interfaces for LeTrain. It emphasizes the charm of retro-style terminal UIs, leveraging ANSI/ASCII art and roguelike-inspired design principles.

## Workflow

### Step 1: Interface Planning
- Define the purpose and functionality of the terminal interface.
- Sketch the layout using ASCII art or grid-based tools.
- Choose a color palette (e.g., 16-color ANSI).

### Step 2: Prototype Development
- Use libraries like Lanterna or ncurses for terminal UI development.
- Implement basic navigation and interaction.
- Focus on readability and usability.

### Step 3: Aesthetic Enhancements
- Add ANSI/ASCII art for visual appeal.
- Use animations or transitions sparingly to enhance the experience.
- Ensure the design aligns with the retro/roguelike theme.

### Step 4: Usability Testing
- Test the interface for clarity and ease of use.
- Gather feedback from users familiar with terminal-based games.
- Iterate on the design based on feedback.

### Step 5: Performance Optimization
- Ensure the interface performs well on low-spec systems.
- Optimize rendering for minimal latency.
- Avoid excessive use of system resources.

## Decision Points
- **Aesthetics vs. Functionality**: Balance visual appeal with usability.
- **Color Palette**: Choose colors that enhance readability and fit the theme.

## Quality Criteria
- Interface is intuitive and easy to navigate.
- Design adheres to retro/roguelike principles.
- Performance is smooth on low-spec systems.
- Visual elements enhance, not hinder, usability.

## Example Prompts
- "Design a terminal UI for train scheduling."
- "Add ANSI art to the main menu."
- "Optimize the terminal interface for low-spec systems."
