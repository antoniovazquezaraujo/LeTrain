# Directrices de Diseño UI (UX)

- **Jerarquía Visual**: Priorizar la información crítica (estado del tren, economía) sobre la decorativa.
- **Consistencia**:
    - **Tipografía**: Usar `JuliaMono` para todo el texto. Mantener tamaños consistentes entre el HUD 3D y la Terminal.
    - **Color**: Usar colores semánticos (ej. rojo para bloque ocupado, verde para despejado) que sean daltónico-accesibles.
- **Espaciado (White space)**: En la terminal, no saturar la pantalla. En 3D, mantener el HUD limpio y fuera de la línea de visión principal del jugador.
- **Feedback**: Toda interacción (clic, comando, tecla) debe tener una respuesta visual inmediata (cambio de color, animación, texto en consola).
